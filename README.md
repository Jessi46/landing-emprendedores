# Documentación del Proyecto - Landing Page

## Paso 1.1 — Inventario de la Landing Actual

* ¿Qué secciones tiene?
  - Encabezado / Navegación (Header)
  - Sección principal (Hero)
  - Beneficios / Características
  - Testimonios
  - Formulario de contacto
  - Pie de página (Footer)

* ¿Qué partes son dinámicas?
  - Formulario de contacto (validación de campos).
  - Menú de navegación (resaltado de la sección activa al hacer scroll).
  - Sección de testimonios (carga dinámica de datos).

* ¿En qué archivo(s) .js está la lógica actual?
  - En el archivo js/main.js.

## Paso 1.2 — Requerimientos del Sitio Web

### Requerimientos Funcionales
- El formulario de contacto valida que los campos de nombre, correo y mensaje no estén vacíos y tengan un formato correcto.
- Los datos ingresados en el formulario se guardan y se pueden leer en formato JSON.
- El menú de navegación resalta visualmente la sección en la que se encuentra el usuario.
- La sección de testimonios se genera dinámicamente desde una lista de datos.

### Requerimientos No Funcionales
- La página web debe ser amigable, intuitiva, funcional y adaptables a diferentes pantallas (responsive).
- El código debe estar tipado utilizando TypeScript y organizado mediante el paradigma de Programación Orientada a Objetos (POO).
